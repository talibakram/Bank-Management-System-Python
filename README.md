# Bank Management System 🏦

A fully functional, crash-proof console application developed in Python. This project simulates real-world banking operations with a strong focus on data validation, user security, and persistent storage. 

### 🚀 Key Features:
* **Robust Error Handling:** Completely crash-proof operations using nested loops, `try-except` blocks, and strict input validation (preventing string crashes, empty inputs, and negative values).
* **Persistent Data Storage:** Uses JSON to save account details, balances, and records safely even after the program closes.
* **Secure User Authentication:** Pin-based login system with duplicate data prevention for phone numbers and emails.
* **Core Financial Operations:** Deposit, Withdraw (with a user cancellation feature), and Money Transfers with receiver verification (prevents self-transfers).
* **Account Management:** Includes account creation (requires 18+ age), viewing profile details, smart profile updates, and account deletion.
* **Transaction Logs:** Generates detailed, timestamped history for all financial activities.

### 🛠️ Tech Stack & Concepts Used:
* **Language:** Python 3
* **Core Concepts:** Object-Oriented Programming (OOP), Dictionary & List Comprehensions, File Handling (JSON), Control Flow, and Exception Handling.
